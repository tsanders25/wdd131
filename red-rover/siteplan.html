Red Rover

Site Name

red-rover.com Red Rover use to be a game we played as kids where one kid would try to break the other team's line. If you couldn't break the line, you were added to the other Team. Red-rover the study game is similar in principle in that if you don't answer the question quick enough or right, you're moved to the other team.

Site Purpose

The purpose of this site is to create a group study game. Users should be able to upload a document filled out in a question and answer format. The website ideally will have a series of logic in js that will create teams and go through a game using the uploaded questions.

Scenario 1

A user downloads a google sheets or excel template and fills it out according to the instructions. They can do what ever subjet they would like as long as the format is question/answer

Scenario 2

A user with their friends or a teacher with their class uploads a series of questions and then selects which game they would like to play. There are several options and each have their own required JavaScript logic.
